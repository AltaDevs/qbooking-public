GitHub repository: `AltaDevs/qbooking-public`

Suggested GitHub description: `Public updates/showcase/roadmap`

## What Q-Booking is

Q-Booking is a booking and queue-management system for local service businesses that want to move from scattered messages and manual scheduling into a cleaner booking flow.

The product is currently focused on controlled launch with appointment-based businesses such as barbershops, salons, clinics, car washes, home services, pet care, photography, and other local service teams.
